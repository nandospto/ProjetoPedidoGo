# ProjetoPedidoGo

Nome do sistema: Sistema de Pedidos para Balcão
Objetivo do sistema:

O Sistema tem por objetivo fazer um sistema simples de pedidos de balcão com estrutura para adicionar, atualizar e remover pedidos. O projeto utiliza de Golang além de um banco de dados simples em SQLlite.

Principais funcionalidades:
- Adição de um pedido com uma lista de itens;
- Atualização de status de pedido;
- Remoção de pedido do banco de dados;
